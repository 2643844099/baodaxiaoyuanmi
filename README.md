# NEO STRIKE 量子突击 — 科幻风 3D 第一人称射击

> **🌐 在线试玩(GitHub Pages):https://2643844099.github.io/baodaxiaoyuanmi/** — 无需下载,任何设备打开浏览器即可游玩!

基于原版 `fps-game` 的**科幻重制版**:原文件夹保持不动,本文件夹为独立的新版本。
更大的多层地图、等离子武器、悬浮机器人敌人、霓虹全息场景,单文件离线可玩。

直接双击打开 `index.html` 即可游玩。**单文件、离线可用**,无需安装任何依赖或启动服务器。

## 玩法

### 关卡系统(共 3 关,由易到难;每关击杀配额达标后需击败 Boss「小圆咪」才能过关)

| 关卡 | 协议名 | 同屏敌人 | 过关击杀数 | 敌人特点 |
| --- | --- | --- | --- | --- |
| 第 1 关 | 训练协议 | 10(4 枪手 + 3 猎杀者 + 3 士兵) | 15 | 血量 100,移动/射速/伤害较低,视野 24 |
| 第 2 关 | 突袭协议 | 15(6 枪手 + 4 猎杀者 + 5 士兵) | 20 | 血量 130,各项属性提升,视野 28 |
| 第 3 关 | 灭绝协议 | 15(5 枪手 + 5 猎杀者 + 5 士兵) | 25 | 血量 160,子弹更快更痛,重生更快,视野 32 |

- 顶部 HUD 显示**当前关卡与击杀进度条**;达到击杀数后,Boss「小圆咪」登场(顶部显示其红色血条),**击败 Boss 才能过关**,获得通关奖励分
- 过关界面显示本关用时/奖励/总分,点击进入下一关;第 3 关通过后进入**全部通关结算**
- 死亡后点击**重新挑战本关**(总分保留),每关开始满血满弹药

### 战利品掉落

- 击杀敌人后掉落战利品:**能量电池**(85% 概率,+15~25 发能量)和 **纳米医疗包**(22% 概率,+25 装甲)
- 战利品落地后旋转发光,走进 1.4 米内自动吸附拾取,屏幕显示 `+X 子弹 / +25 生命`
- 战利品 25 秒后消失,最后 3 秒闪烁提示

### 敌人 AI(第一时间追踪攻击)

- **所有敌人(含 Boss)从出现起就锁定玩家位置,第一时间追击攻击,永不脱战、永不放弃**
- 被掩体挡住视线时会绕路逼近,进入射程且有视线时开火(子弹会被掩体吸收,躲墙后仍有效)
- 待机时核心指示灯为青色,**追击/攻击时变为红色并脉动**
- **不同敌人使用不同色调,高可视度**:枪手=亮钢蓝、猎杀者=亮品红、未来士兵=亮琥珀橙,弹道颜色与机体一致(青/红/橙)
- 所有敌人体积比原版更大,头部位于**水平瞄准略偏上**的位置,爆头更容易
- 身体中 3 枪(每枪 34 伤害)报废,**爆头一击必杀**;死亡时爆炸并产生扩散能量冲击波,随后按关卡配置在远处重生
- 被击中会掉血(红屏 + 镜头震动),脱战 4 秒后缓慢回血;血量为 0 游戏结束

### 猎杀者(近战高速型)

- 低矮流线型机体 + 前臂双刃,品红核心指示灯,移动速度约为枪手的 **1.7 倍**
- 发现玩家后高速直冲,贴近(约 2 米)后发动**近战突刺**(伤害 18,冷却 0.9 秒)
- 突刺有前摇动画,突刺中段判定伤害——**后退即可躲开**
- 血量较低(70),两梭子即可解决;不会发射子弹,但贴脸威胁极大,优先击杀!

### 未来士兵(远程人形小兵)

- 人形作战单位:穿戴**装甲防具**(胸甲 + 肩甲 + 头盔),手持**未来步枪**(发光枪口 + 能量电池 + 瞄准镜)
- 双腿行走动画,点射间隙步枪会下沉做出**预备/换弹姿态**
- **三连发点射**(单发伤害均分,总伤害与枪手相当),血量约为同关枪手的 90%
- 头部(头盔)爆头一击必杀

### Boss「小圆咪」(每关 1 台)

- **独立建模**的巨型战斗机甲:反重力巨环 + 厚重装甲 + 胸口能量核心 + 双肩重型等离子炮,体积约为小兵的 **3 倍**
- 血量约为普通敌人的 **13 倍**(第 1/2/3 关:1300 / 1690 / 2080)
- **移动速度更快、攻击范围更远**(30 米),进入射程后站桩**多管齐射**(3~5 发散射等离子弹),压迫感十足
- **免疫爆头一击必杀**,只能硬碰硬磨血;死亡时连环爆炸并通关本关
- 出现时屏幕顶部显示红色血条与名称「小圆咪」,同时**头顶出现全图可见的闪烁光标**:屏幕内时指向 Boss 头顶,屏幕外时贴边显示方向箭头,无论在地图哪里都能第一时间找到 Boss
- 击杀奖励 +500 分

### 科幻地图(比原版大 4 倍,立体结构)

- 战场从 90×90 扩大为 **180×180**,深空星空穹顶 + 霓虹网格金属地面
- **中央能量核心塔**:高台(高 7 米)+ 四座中部平台(高 3.5 米)+ 8 条坡道连接,可登上塔顶获得视野优势(敌人会绕路上来)
- 全息旋转环、能量光柱、四角哨戒塔、四座实验室建筑、科技货箱/能量屏障/发光灯柱等掩体
- 平台侧墙会阻挡子弹与视线,坡道可正常行走;**占领高台可俯射下方敌人**
- 坡道/高台下方可正常通行——从桥底穿过不会被传送到坡面上

### 得分

击杀 +100,爆头击杀 +150;Boss 击杀 +500;通关奖励:第 1/2/3 关分别为 +300/+600/+900。

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | **最终成品**——Three.js 与全部游戏代码内联,直接打开即玩 |
| `template.html` | 页面骨架与霓虹 HUD 样式 |
| `game.js` | 游戏逻辑(玩家、机器人 AI、关卡、战利品、特效、音效) |
| `three.min.js` | Three.js r128 库文件 |
| `build.ps1` | 重新打包生成 index.html |
| `check.js` | 构建完整性校验(占位符/ID 对应) |
| `smoketest.js` | Node 无头冒烟测试(模拟完整三关流程,可用环境变量 `SEED` 指定随机种子) |
| `realthree-check.js` | 用真实 three.min.js 校验启动路径无 API 错误 |

## 修改后重新打包

修改 `game.js` 或 `template.html` 后,在 PowerShell 中运行:

```powershell
.\build.ps1
```

## 验证

```powershell
node check.js      # 构建完整性校验
node smoketest.js  # 无头冒烟测试(无需浏览器)
```

### 难度调整

修改 `game.js` 顶部的 `LEVELS` 配置数组即可调整每关的敌人数、过关击杀数、血量、速度、开火间隔、子弹速度/伤害、视野和重生时间。

### 地图调整

地图尺寸由 `ARENA` 常量控制(半宽,单位米);中央高台/中部平台/坡道在 `buildWorld()` 中通过 `addPlatform()` 与 `addRampMesh()` 配置,可自由增删平台层级。
